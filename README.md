# AutoHisab

Phase 1 of a mobile-first, Pakistan-focused vehicle ownership and fuel-cost calculator built with Next.js App Router, TypeScript, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. Set `NEXT_PUBLIC_SITE_URL` to the production origin before deployment so canonical links, Open Graph metadata, sitemap, and robots output use the correct domain.

## Checks

```bash
npm test
npm run lint
npm run typecheck
npm run build
```

Phase 1 intentionally has no database, authentication, payments, analytics, or advertising code.
